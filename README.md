## 🔐 OPERATIONAL MISSIONS

### 01 // MISSION OMEGA VAULT (FEDERAL RESERVE)

Infiltrate the Federal Reserve's primary mainframe and dismantle **9 layers** of multi-phase encryption.

- **Objective:** Exfiltrate $4.2T in unmarked assets.
- **Protocol:** High-precision timing and logic gates.

Breach the Silicon Valley Quantum Core using the **Spectral Decoder**.

Hijack the military's global surveillance constellation.

## 🛠 CORE FEATURES

- **Cinematic Deployment:** Immersive mission briefing flow with typewriter-style transmissions and tactical data visualization.
- **Dynamic Encryption Engines:**
   - **Timing Gates:** High-speed orbital intersection puzzles.
   - **Memory Bursts:** Sequential pattern recognition.
   - **Logic Gates:** Rapid arithmetic/logical validation.
   - **Signal Sync:** Real-time waveform alignment using advanced manual controls.
- **Campaign Command Center:** Chronological mission locking system with persistent data tracking via `localStorage`.
- **Haptic Audio Environment:** Custom `SoundSystem` class using Web Audio API for real-time thuds, chirps, and ambient drones.
- **Obsidian & Neon Aesthetic:** Premium dark-mode interface built with high-fidelity CSS transitions, glassmorphism, and neon-cyan visual accents.

## 🚀 TECHNICAL STACK

- **Logic Engine:** Vanilla JavaScript (ES6+)
- **Audio:** Web Audio API (Synthesized oscillators and noise buffers)
- **Graphics:** HTML5 Canvas API (Particle Systems, Dynamic Waveforms)
- **Styling:** Vanilla CSS3 (Custom Design Tokens, Keyframe Animations)
- **Persistence:** Browser `localStorage` API
